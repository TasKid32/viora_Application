# 🎯 فيورا (Viora) — منصة ذكية لتطوير المسار المهني
### نظام مدعوم بالذكاء الاصطناعي لتحليل السير الذاتية وتخطيط المسارات الوظيفية

---

## ⚙️ تشغيل البيئة والسيرفر (Backend Startup)
قبل البدء بتشغيل المشروع، فعّل البيئة وشغّل السيرفر بهذه الأوامر:

```bash
# تفعيل البيئة (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# تشغيل السيرفر
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

## 🛠️ التقنيات المستخدمة
* **تطبيق الجوال:** Flutter & Dart (Provider, Dio, GoRouter).
* **النظام الخلفي (Backend):** Python (FastAPI, SQLAlchemy, Pydantic V2).
* **محرك الذكاء الاصطناعي:** RoBERTa NER (ONNX Quantized).
* **قواعد البيانات المهنية:** O*NET Taxonomy & ESCO v1.2.1.
* **النموذج اللغوي (LLM):** Google Gemini 2.5 Flash (للمساعد الذكي فقط).
* **قاعدة البيانات:** SQLite للتطوير وPostgreSQL للإنتاج.

## 🏗️ هيكلة المشروع
يتم تنظيم المشروع في ثلاث مجلدات رئيسية لضمان سهولة الإدارة:
* **`backend/`**: يحتوي على السيرفر، قاعدة البيانات، والخدمات المنطقية.
* **`mobile/`**: يحتوي على كود تطبيق الجوال المطور بـ Flutter.
* **`ml/`**: يحتوي على موديلات الذكاء الاصطناعي وقواعد البيانات المهنية.

## 🔄 آلية عمل الذكاء الاصطناعي (AI Pipeline)
تعتمد المنصة على "خط إنتاج" ذكي يضمن سرعة التحليل في أقل من **200 مللي ثانية**:

1. **الاستخراج (Extraction):** تحويل الملفات المرفوعة إلى نص رقمي نظيف.
2. **محرك الـ NER:** تصنيف الكلمات إلى 8 أنواع (مهارات، وظائف، شركات، إلخ).
3. **المطابقة (Matching):** مقارنة المهارات المستخرجة مع وظائف معتمدة في O*NET.
4. **التحليل (Analysis):** تحديد "الفجوة المهارية" واقتراح المسار التعليمي المناسب.

## 🚀 دليل التشغيل (Setup Guide)

### 1. تحميل المشروع
```bash
git clone https://github.com/TasKid32/viora_Application.git
```

### 2. إعداد الباك اند (Backend)
```bash
cd backend
python -m venv venv
# تفعيل البيئة (Windows)
.\venv\Scripts\Activate.ps1
# تثبيت المكتبات
pip install -r requirements.txt
```

### 3. تحميل الموديلات والبيانات (ML Data)
> ⚠️ **خطوة إلزامية:** يجب تشغيل هذا السكربت لتحميل الموديلات والبيانات (حوالي 1.6 جيجابايت).

```bash
cd ..
python setup_ml_data.py
```

### 4. تشغيل التطبيق (Mobile)
```bash
cd mobile
flutter pub get
flutter gen-l10n
# تشغيل التطبيق (استبدل YOUR_IP بـ IP جهازك)
flutter run --dart-define=API_URL=http://YOUR_IP:8000
```
