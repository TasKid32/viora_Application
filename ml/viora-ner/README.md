# 🧠 Viora NER Engine
### Named Entity Recognition for Smart CV Analysis

## 📋 نظرة عامة
يعتمد مشروع **Viora** على محرك ذكاء اصطناعي متخصص في "تعريف الكيانات المسماة" (NER). يقوم هذا المحرك بقراءة السير الذاتية وتحليلها بدقة لاستخراج المعلومات الجوهرية آلياً، مما يلغي الحاجة للإدخال اليدوي.

## 🚀 المميزات التقنية
* **الموديل الأساسي:** يعتمد على هندسة `RoBERTa` المتطورة لفهم سياق الكلام.
* **السرعة والكفاءة:** تم استخدام تقنية `ONNX` لضمان استخراج البيانات في أقل من **100 مللي ثانية**.
* **الخصوصية:** معالجة البيانات تتم محلياً بالكامل (Local Inference) دون الحاجة لإرسال الملفات لخوادم خارجية.

## 🔍 البيانات المستخرجة (8 أنواع)
يقوم النظام بتصنيف الكلمات إلى:
1. **المهارات (Skills):** تقنية وشخصية.
2. **المسميات الوظيفية (Job Titles).**
3. **الجهات (Organizations):** شركات وجامعات.
4. **الشهادات (Credentials):** درجات علمية واعتمادات.
5. **الخبرات (Experience):** الفترات الزمنية للعمل.
6. **معلومات التواصل (Contact).**
7. **الأسماء (Person).**
8. **المواقع (Location).**

## 🛠️ كيف يعمل النظام؟
1. **التنظيف:** تحويل ملفات الـ PDF/Docx إلى نص رقمي.
2. **التصنيف:** يقوم الموديل المدرب (Fine-tuned) بتمييز كل جزء من النص.
3. **المطابقة:** ربط النتائج بمعايير **O*NET** العالمية لتحديد الفجوات المهارية.
