# ⚙️ Viora Backend Engine
### Smart Career Development System — Backend Server

## 📋 نظرة عامة
يعد النظام الخلفي (Backend) لـ **Viora** هو المحرك الأساسي لإدارة العمليات، حيث يربط بين تطبيق الجوال، قاعدة البيانات، ومحرك الذكاء الاصطناعي. تم بناؤه باستخدام تقنية **FastAPI** لضمان سرعة فائقة وكفاءة في معالجة البيانات.

## 🚀 المميزات التقنية
* **الأداء العالي:** استجابة سريعة جداً لتحليل السير الذاتية في أقل من **200 مللي ثانية**.
* **التحليل المحلي:** معالجة السير الذاتية تتم محلياً بالكامل (Local) لضمان أقصى درجات الخصوصية والسرعة.
* **المطابقة الوظيفية:** نظام ذكي مرتبط بمعايير **O*NET** العالمية لتقديم نصائح مهنية دقيقة.
* **البحث المتكامل:** البحث الآلي عن دورات تدريبية في منصات (YouTube, Coursera, Udemy).

## 📂 الهيكل التنظيمي للنظام
* **الواجهات البرمجية (API):** إدارة عمليات التسجيل، رفع الملفات، والدردشة الذكية.
* **الخدمات الذكية (Services):** محرك تحليل المهارات، نظام تحديد الفجوات المهارية، ومولد مسارات التعلم.
* **قاعدة البيانات (DB):** تخزين آمن لبيانات المستخدمين وسيرهم الذاتية باستخدام SQLAlchemy.

## 🔒 الأمن والخصوصية
* نظام تشفير كلمات المرور (Bcrypt).
* حماية الدخول باستخدام Dual JWT (Access & Refresh tokens).
* معالجة الملفات وحذفها فور الانتهاء من التحليل لضمان الأمان.
